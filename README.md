# Morphogenesis website clone

A local Next.js recreation of the public Morphogenesis website. It includes 566 routes, local media, and responsive layouts based on the captured source.

## Run locally

Requires Node.js 24 or later.

```sh
npm ci
npm run dev
```

Open `http://localhost:3000`. Run `npm run check` for linting, TypeScript checks, and a production build.
